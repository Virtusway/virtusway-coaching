## 3. Tecnologías Clave (Frontend)
*   **Framework:** Astro 6.x.
*   **Estilos:** Tailwind CSS v4.
*   **Despliegue/Hosting:** Netlify (detectado por `@astrojs/netlify` en `astro.config.mjs`).

## 4. Directrices de Desarrollo y Git (Decision Log)
*   **Idiomas de las Ramas:** Los nombres de las ramas de Git se escribirán **siempre en inglés** (por ejemplo: `UX-UI`, `feature/hero-redesign`, `hotfix/header-scroll`).
*   **Flujo de Aprobación:** Toda nueva funcionalidad o cambio de diseño se subirá en su respectiva rama para revisión técnica y del cliente (Mauricio) antes de integrarse a la rama principal.
